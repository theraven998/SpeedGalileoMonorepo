Esto también es un experimento

¿Un ranking entre cursos mejora la puntualidad, o termina generando presión entre compañeros? El proyecto de Diego mide las dos cosas — incluso si el resultado sale negativo.

Semanas 1–2

Se registra todo, pero el tablero está oculto.

Semanas 3–4

Se publica el ranking y empieza la competencia.

Al final

Se comparan resultados y se encuesta a los estudiantes.
